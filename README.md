# Internationalization for .NET Learning Project for EESAST Summer Training

[`dotnet-workshop`](https://github.com/eesast/dotnet-workshop) is a .NET learning project for EESAST Summer Training. The original documentation of the repository is written in simplified Chinese. This repository provides documentation with multiple languages.
